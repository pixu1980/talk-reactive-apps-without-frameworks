Step 6 - store emits store:change

Store does not expose raw internal references. It clones payload before dispatching the event.

emitChange


emitChange(path, oldValue, newValue) {
  const detail = {
    path: pathToString(path),
    oldValue: deepClone(oldValue),
    newValue: deepClone(newValue),
  }

  const event = new CustomEvent("store:change", { detail })
  this.events.dispatchEvent(event)
}

Example detail


{
  path: "todos.1",
  oldValue: {
    title: "Refine the keyed repeat engine",
    completed: false,
  },
  newValue: {
    title: "Refine the keyed repeat engine",
    completed: true,
  },
}
Event path is useful for debug output and persistence. It is not used as a granular dependency graph in this demo.
