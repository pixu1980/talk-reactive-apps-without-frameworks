Step 8 - tickState is deliberately noisy

`tickState` uses an equality function that always returns false. Every `set()` notifies subscribers, even if numeric value looks similar.

StateSignal


export const tickState = new Signal.State(0, { equals: () => false })

export class StateSignal extends BaseSignal {
  get() {
    this.track()

    return this.value
  }

  set(nextValue) {
    if (this.equals(this.value, nextValue)) return this.value

    this.value = nextValue
    this.notify()

    return this.value
  }
}

notify


notify() {
  for (const subscriber of [...this.subscribers]) subscriber()
}
`tickState` means: no business meaning, just a pulse.
