Step 14 - DOM parts commit final changes

When `TodoItem(nextTodo)` runs again, `isDone` changes from false to true. Different expressions land in different part types.

TodoItem updates


const isDone = todo.completed

return html`
  <article
    data-component="todo-item"
    data-priority=${todo.priority}
    data-state=${isDone ? "done" : "open"}
  >
    <input
      aria-label=${t(language, "fields.title")}
      aria-readonly=${String(isDone)}
      data-slot="title"
      model=${todoModel(todo.id, "title")}
      readonly=${isDone}
    />
  </article>
`

Part types

  • `data-state=${"..."}` lands in AttributePart
  • `readonly=${"..."}` lands in AttributePart
  • `model=${"..."}` lands in `AttributePart.commitModel()`
  • Text content lands in ChildNodePart
  • Event bindings like `@click=${"..."}` land in EventPart

Direct DOM writes


commit(value) {
  if (value == null || value === false) {
    this.element.removeAttribute(this.name)
    return
  }

  this.element.setAttribute(this.name, value === true ? "" : String(value))
}

commitNode(node) {
  clearRange(this.start, this.end)
  this.currentNode = node
  this.start.parentNode.insertBefore(node, this.end)
}
