Step 9 - computed signals become dirty

Computed signals read `tickState` to join that pulse. First evaluation subscribes them to future ticks.

visibleTodos


export const visibleTodos = new Signal.Computed(() => {
  tickState.get()

  return pipelineTodos(
    store.state.todos,
    store.state.filters,
    store.state.preferences.language,
  )
})

dependency + invalidation


addDependency(signal) {
  if (this.dependencies.has(signal)) return

  const unsubscribe = signal.subscribe(this.boundInvalidate)
  this.dependencies.set(signal, unsubscribe)
}

invalidate() {
  if (this.dirty) return

  this.dirty = true
  this.notify()
}

get() {
  this.track()

  return this.evaluate()
}
Computed value is lazy. It does not recompute during invalidation. It recomputes on next `get()`.
