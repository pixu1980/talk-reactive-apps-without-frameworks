Step 2 - `todoModel()` builds read and write contract

`todoModel()` wraps the field in a directive payload. Renderer receives three things: signal for resync, getter for current value, setter for next value.

`todoModel`


export function todoModel(todoId, field, options = {}) {
  return model({
    signal: tickState,
    get: () => getTodoById(todoId)?.[field] ?? (options.prop === "checked" ? false : ""),
    set: (value) => updateTodo(todoId, { [field]: value }),
    ...options,
  })
}
For checkbox: `field` is completed, `prop` is checked, and `event` is change.
