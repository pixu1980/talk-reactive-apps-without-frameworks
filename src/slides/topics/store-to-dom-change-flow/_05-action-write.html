Step 4 - action writes into proxy store

`updateTodo()` finds the item and replaces it with a new object containing the patch.

updateTodo


export function updateTodo(id, patch) {
  const index = store.state.todos.findIndex((todo) => todo.id === id)

  if (index < 0) {
    return
  }

  const current = store.state.todos[index]

  store.state.todos[index] = { ...current, ...patch }
}

Logical field, actual write


// Logical change
todo.completed = true

// Actual app write
store.state.todos[index] = {
  ...current,
  completed: true,
}
Store event path is array slot, for example `todos.1`, not deep path `todos.1.completed`. Field changed, but proxy assignment replaced whole todo object.
