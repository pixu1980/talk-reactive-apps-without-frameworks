Step 1 - component binds a field to `model()`

`TodoItem()` renders a checkbox for the completed field. Template does not wire the field manually. It passes a model directive to the template engine.

TodoItem checkbox


export function TodoItem(todo) {
  const language = store.state.preferences.language
  const isDone = todo.completed

  return html`
    <label data-control-group="checkline" data-slot="completion-toggle">
      <input
        model=${todoModel(todo.id, "completed", {
          prop: "checked",
          event: "change",
        })}
        type="checkbox"
      />
      <span>${t(language, "labels.done")}</span>
    </label>
  `
}

Mental model

  • `model=...` becomes an `AttributePart` because it is in an attribute position
  • `todoModel(...)` describes how to read and write that field
  • Checkbox stays a normal native input
